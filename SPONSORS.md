# Sponsor this work 💖

Hi — I'm **Chandra** ([@chandrasaripaka](https://github.com/chandrasaripaka)). I build open-source developer tools, AI/agent systems, and experiments in public. Sponsorship keeps that work sustainable and lets me spend more time maintaining, documenting, and shipping.

## Ways to support

**With money**
- **GitHub Sponsors** (recurring or one-off): https://github.com/sponsors/chandrasaripaka
- **Ko-fi** (quick one-off tip, no account needed): https://ko-fi.com/chandrasaripaka

**Without money — just as valuable**
- ⭐ **Star** the repos you use — visibility is what attracts contributors and sponsors.
- 🐛 **Contribute** — bug reports, pull requests, docs, and translations.
- 📣 **Tell people** — a blog post, tweet, or mention at work goes a long way.
- 🎯 **Fund a feature/issue** — comment on an issue you'd like prioritized.

## Sponsor tiers

| 🌱 **Supporter** | $10 / mo | Above + name & link in the README of a project of your choice. |
| 🚀 **Backer** | $25 / mo | Above + priority on issue triage and questions. |

| 💎 **Partner** | $500 / mo | Above + a dedicated feature/consulting slot each month. |

**One-off tiers** (GitHub Sponsors supports these too):

- **$50 — "Fund a feature"** — put toward a specific improvement.
- **$250 — "Sponsor a release"** — credited in the next release notes.
