# Validate with the brain, always

Standing operator preference: "validate with the brain, always."

**Why:** the brain (`INDEX.md` + cells) caches what was already learned; skipping recall re-derives
solved problems and repeats known mistakes — the exact token/effort leak the brain exists to stop.

**How to apply:** before generating code, planning, or researching ANY task, run G1 RECALL — `grep`
INDEX.md for the relevant `@tags` and read the matched cells; reuse what's there. Don't treat the Gate
loop's RECALL as optional even for seemingly-small asks. Then write back (G5) what's durable. Treat it
as non-negotiable, not a shortcut that gets skipped under time pressure.
